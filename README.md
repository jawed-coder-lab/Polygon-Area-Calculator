Polygon Area Calculator

A Python program that calculates properties of rectangles and squares using object-oriented programming.

About the Project

This project was completed as part of the Python Certification Projects in the "freeCodeCamp" (https://www.freecodecamp.org/) curriculum.

The project implements "Rectangle" and "Square" classes and provides methods for calculating areas, perimeters, diagonals, and other properties of geometric shapes.

Features

The "Rectangle" class provides methods to:

- Calculate the area
- Calculate the perimeter
- Calculate the diagonal
- Generate a visual representation of the shape
- Calculate how many times another shape can fit inside it

The "Square" class inherits from "Rectangle" and provides square-specific functionality.

Example

rectangle = Rectangle(10, 5)

print(rectangle.get_area())
# 50

print(rectangle.get_perimeter())
# 30

square = Square(5)

print(square.get_area())
# 25
